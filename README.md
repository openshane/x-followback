# 𝕏 回关助手

一个中文 Chrome 侧栏扩展，帮你找出 X 认证关注者中，你还没回关的人。可以查看对方简介、打开主页，再决定是否关注。

![扩展图标](icons/icon-48.png)

## 安装

需要 Chrome 116 或更高版本。

1. 在 GitHub 点击 **Code → Download ZIP**，将下载的文件解压。
2. 打开 `chrome://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」。
3. 选择包含 `manifest.json` 的目录，将「𝕏 回关助手」固定到工具栏。

## 使用

在同一 Chrome 窗口登录 X，打开扩展侧栏，确认显示的是自己的账号后点「开始扫描」。扩展会打开或复用该账号的认证关注者页。扫描时保持名单页和侧栏打开，可以暂停、继续或提前结束。

- 点「我未回关」或「蓝 V 且我未回关」筛选名单，再按用户名或显示名搜索。CSV 导出当前筛选和搜索命中的全部记录。
- 已申请关注和关系待确认的账号会单独列出。第一次完整扫描建立基线，后续的「新发现」显示相比上次完整扫描多出的、目前确认未回关的账号。
- 如果中途停止、切换页面或没有读到可信的末页，侧栏会说明扫描未完整，并保留上次完整记录。X 页面结构或响应字段的变化可能影响识别。

## 权限与数据

扩展使用 `scripting` 在 `x.com` 标签页识别登录账号，用 `sidePanel` 展示名单，用 `storage.local` 按账号保存最近一次完整扫描的用户 ID、用户名、显示名、简介、关系标记和扫描时间。名单在本机处理。点「清空数据」并确认即可删除当前账号的记录。

## 开发

项目使用原生 JavaScript 和 Chrome Manifest V3，无需安装依赖或构建。直接加载仓库根目录即可调试。修改文件后在扩展管理页点「重新加载」，再重开侧栏。
